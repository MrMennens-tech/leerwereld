📂 App Icons Installatie:
  1. Download beide PNG bestanden hierboven
  2. Hernoem ze naar icon-180.png en icon-512.png
  3. Upload ze naar dezelfde map als je index.html
  4. De code is al aangepast om deze bestanden te gebruiken!
🔖 Favicon Installatie:
  1. Download favicon.ico (of beide PNG bestanden)
  2. Upload favicon.ico naar de root van je website
  3. Browsers vinden het automatisch op /favicon.ico
  4. Optioneel: Voeg toe aan je HTML: 
    <link rel="icon" type="image/x-icon" href="/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16.png">
